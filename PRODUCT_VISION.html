What happens when a batch is uploaded

Six stages, every one of them explainable on demand. Filled dots mark logic that runs for real today; outlined dots mark the connection to ATCO's live services, planned next.

01

Ingestion & Parsing

Reads the workbook, maps ATCO's field names — or the ESRI table's own headers — onto a structured record, and sets aside any row that can't be read before it ever reaches validation.

● Live today
02

Rule Validation

Checks every populated field against the approved Legal / Civic / Rural combination matrix — Required, Optional, or Not Allowed — the same matrix your team signs off on.

● Live today
03

Geocoding Analysis

Confirms the address resolves to a real location, checks match confidence, and flags candidates that drift from the expected Service Point.

○ Connects to ATCO's reconfigured geocoder
04

Maximo Readiness

Simulates the dispatch payload against Maximo's real schema before anything is sent — catching missing or conflicting fields early, never after submission.

○ Connects to Maximo's REST channel
05

AI Narration

Azure OpenAI turns the structured result into a plain-language explanation, and answers follow-up questions by re-running the same checks live — never by guessing.

● Live today
06

Post-Update Reconciliation

After a record is dispatched through the existing GIS/Maximo channel, confirms both systems ended up in sync — and raises a flag the moment they don't.

○ Requires live GIS/Maximo read access

What it will never do

The Agent's authority stops at recommendation. These aren't settings — they're the boundary the system is built around.

Guardrails

  • Read-onlyNever writes to GIS or Maximo, under any condition.
  • No new write pathDispatch still goes through ATCO's existing, governed channel.
  • Address fields onlyScoped strictly to Service Point address data.
  • Human stays in controlEvery what-if is a simulation — nothing is ever saved automatically.
  • Explains, never decidesStatus is computed by rules before the AI ever narrates it.

About this page. This is a scripted walkthrough built for stakeholder review — it demonstrates the target production experience, not a live system.
